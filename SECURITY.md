# Security policy

## Supported versions

Security fixes are made for the latest minor release.

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub security advisories](https://github.com/lobojoel2003/Factfinch/security/advisories/new) rather than in a public issue. You can expect an acknowledgement within a week.

## Privacy

The demo runs entirely in the browser. Answers are kept in the browser's local storage on your device and are never sent to a server. "Start over" clears them.
